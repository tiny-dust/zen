# F2: OpenAI Codex CLI 与 Google Gemini CLI 的自动压缩与恢复机制

调研日期: 2026-10-12。所有来源均为当日抓取的官方一手文档（OpenAI 开发者文档站、gemini-cli main 分支仓库文档、Qwen Code 官方文档站）。

## Findings

### [1] Codex CLI 通过 `model_auto_compact_token_limit` 配置自动压缩触发阈值，未设置时使用各模型的默认值
- quote: "model_auto_compact_token_limit — Token threshold that triggers automatic history compaction (unset uses model defaults)."（另有 `model_context_window` — "Context window tokens available to the active model."）
- url: https://developers.openai.com/codex/config-file/config-reference.md
- source_type: primary
- published: unknown (docs current as of 2026-10)
- confidence: high

### [2] Codex CLI 的自动压缩阈值可配置计数口径：`model_auto_compact_token_limit_scope` 支持 `total`（默认，统计全部活跃上下文）或 `body_after_prefix`（只统计携带压缩窗口前缀之后的增长），说明其压缩后保留了可跨次复用的"压缩窗口前缀"
- quote: "Controls whether the auto-compaction threshold counts the full active context (`total`, the default) or only growth after the carried compaction-window prefix (`body_after_prefix`)."
- url: https://developers.openai.com/codex/config-file/config-reference.md
- source_type: primary
- published: unknown (docs current as of 2026-10)
- confidence: high

### [3] Codex CLI 的压缩提示词可定制：`compact_prompt` 内联覆盖历史压缩提示词，`experimental_compact_prompt_file` 从文件加载（实验性），并暴露 `PreCompact`/`PostCompact` 生命周期钩子
- quote: "compact_prompt — Inline override for the history compaction prompt." / "experimental_compact_prompt_file — Load the compaction prompt override from a file (experimental)." / hooks 事件含 "`PreCompact`, `PostCompact`"
- url: https://developers.openai.com/codex/config-file/config-reference.md
- source_type: primary
- published: unknown (docs current as of 2026-10)
- confidence: high

### [4] Codex CLI 手动 `/compact` 流程为：确认后用简洁摘要替换更早的对话轮次以释放上下文，同时保留关键细节；`/status` 显示"剩余上下文容量"
- quote: "Confirm when Codex offers to summarize the chat so far. Expected: Codex replaces earlier turns with a concise summary, freeing context while keeping critical details." / "`/status` — Show the chat ID, context usage, and rate limits."
- url: https://developers.openai.com/codex/developer-commands.md
- source_type: primary
- published: unknown (docs current as of 2026-10)
- confidence: high

### [5] Codex CLI 的会话恢复体系：`codex resume`（按 ID 或 `--last`，默认限定当前工作目录、`--all` 全局搜索）、`codex exec resume --last/--all`（非交互续跑）、`codex fork`（分叉旧会话）、`codex archive/unarchive`；跨目录恢复用 `tui.resume_cwd`；可恢复运行时状态存于 SQLite（`sqlite_home`）
- quote: "Continue an interactive session by ID or resume the most recent chat. `codex resume` scopes `--last` to the current working directory unless you pass `--all`." / "sqlite_home — Directory where Codex stores the SQLite-backed state DB used by agent jobs and other resumable runtime state."
- url: https://developers.openai.com/codex/developer-commands.md
- source_type: primary
- published: unknown (docs current as of 2026-10)
- confidence: high

### [6] OpenAI Responses API 提供服务端自动压缩：请求携带 `context_management` + `compact_threshold`（官方示例 200,000 token），渲染 token 超阈值时服务端在响应流中触发压缩、发出"compaction output item"并裁剪上下文后继续推理；该压缩项为加密且不可人读，承载跨窗口的关键状态与推理
- quote: "As the response streams, if the context size crosses the threshold, the server triggers a compaction pass, emits a compaction output item in the same stream, and prunes context before continuing inference." / "It is opaque and not intended to be human-interpretable."（示例：`context_management: [{ type: "compaction", compact_threshold: 200_000 }]`，模型 gpt-5.3-codex）
- url: https://developers.openai.com/api/docs/guides/compaction.md
- source_type: primary
- published: unknown (docs current as of 2026-10)
- confidence: high

### [7] OpenAI Responses API 另有独立 `/responses/compact` 端点：完全无状态、ZDR 友好，输入完整上下文窗口、输出"规范化的下一窗口"（压缩项 + 部分保留项），官方明确要求不得裁剪其输出、原样传入下一次 `/responses`
- quote: "Output handling: do not prune `/responses/compact` output. The returned window is the canonical next context window, so pass it into your next `/responses` call as-is." / "the compacted window generally contains more than just the compaction item. It can also include retained items from the previous window."
- url: https://developers.openai.com/api/docs/guides/compaction.md
- source_type: primary
- published: unknown (docs current as of 2026-10)
- confidence: high

### [8] Gemini CLI 的自动上下文压缩由 `model.compressionThreshold` 控制：以"上下文使用占比"为触发条件，默认 0.5（即用掉 50% 上下文窗口即触发）
- quote: "Context Compression Threshold | `model.compressionThreshold` | The fraction of context usage at which to trigger context compression (e.g. 0.2, 0.3). | `0.5`"
- url: https://raw.githubusercontent.com/google-gemini/gemini-cli/main/docs/cli/settings.md
- source_type: primary
- published: unknown (gemini-cli main branch, fetched 2026-10-12)
- confidence: high

### [9] Gemini CLI 用 `model.maxSessionTurns`（默认 -1 无限）做会话长度上限的兜底：达到上限后交互模式停止向模型发请求并提示手动新开会话，非交互模式直接报错退出——这是压缩之外防止上下文失控的第二道闸
- quote: "`maxSessionTurns`: (number) The maximum number of turns (user and model exchanges) allowed in a single session. Set to `-1` for unlimited (default). ... **Interactive mode:** The CLI shows an informational message and stops sending requests to the model. **Non-interactive mode:** The CLI exits with an error."
- url: https://raw.githubusercontent.com/google-gemini/gemini-cli/main/docs/cli/session-management.md
- source_type: primary
- published: unknown (gemini-cli main branch, fetched 2026-10-12)
- confidence: high

### [10] Gemini CLI 的 checkpointing 在 AI 工具修改文件前自动保存三要素（影子 Git 快照 + 完整对话历史 + 待执行的工具调用），`/restore` 可同时还原文件、恢复对话历史并重新提出原工具调用；该功能默认关闭，`--checkpointing` 命令行标志已在 v0.11.0 移除、只能经 settings.json 的 `general.checkpointing.enabled` 开启
- quote: "This checkpoint includes: 1. **A Git snapshot:** A commit is made in a special, shadow Git repository located in your home directory (`~/.gemini/history/<project_hash>`)... 2. **Conversation history**... 3. **The tool call**" / "The `--checkpointing` command-line flag was removed in version 0.11.0."
- url: https://raw.githubusercontent.com/google-gemini/gemini-cli/main/docs/cli/checkpointing.md
- source_type: primary
- published: unknown (gemini-cli main branch, fetched 2026-10-12)
- confidence: high

### [11] Gemini CLI 会话自动落盘并支持多粒度恢复：历史存于 `~/.gemini/tmp/<project_hash>/chats/`，`--resume`（最近/序号/UUID）与 `/resume` 交互式 Session Browser 恢复；支持命名检查点（`/resume save <tag>` / `resume`）；会话默认保留 30 天（`maxAge: "30d"`，`minRetention: "1d"` 防误删）
- quote: "**Location:** Sessions are stored in `~/.gemini/tmp/<project_hash>/chats/`" / "`/resume save decision-point` ... Compatibility aliases: `/chat ...`" / "The default policy is to **retain sessions for 30 days**."
- url: https://raw.githubusercontent.com/google-gemini/gemini-cli/main/docs/cli/session-management.md
- source_type: primary
- published: unknown (gemini-cli main branch, fetched 2026-10-12)
- confidence: high

### [12] Qwen Code（Gemini CLI fork）重设计了自动压缩阈值：`context.autoCompactThreshold` 默认 0.85 作为触发上限，内部经 `computeThresholds()` 由模型上下文窗口计算三级阈值阶梯（warn / auto / hard），小窗口下为留出摘要空间会提前触发；旧设置 `model.chatCompression.contextPercentageThreshold` 已移除
- quote: "**REMOVED.** Replaced by `context.autoCompactThreshold` ... Auto-compaction now uses a three-tier threshold ladder (warn / auto / hard) computed internally from the model's context window via the `computeThresholds()` function. ... Default is `0.85` (85%). Acts as a ceiling on the trigger: on large windows it is the effective trigger (~85%), while on smaller windows compaction may fire earlier to leave room to summarize."（参见 PR #4345 / docs/design/auto-compaction-threshold-redesign.md）
- url: https://qwenlm.github.io/qwen-code-docs/en/users/configuration/settings/
- source_type: primary
- published: 2026-10-03 (page "Last updated" date)
- confidence: high

### [13] Qwen Code 的压缩执行层：压缩后自动恢复最近触及的文件内容（默认 5 个，小文件内嵌、大文件按路径引用）与最近图片（默认 3 张）；可用独立 `compactionModel`（`/model --compaction`）跑压缩以降本提速；另有无 AI 的 `/compress-fast`（剥离旧工具输出与思考段）和与 token 无关的截图触发器（工具返回图片累计默认 20 张即压缩，压缩后计数重置）
- quote: "Number of most-recently-touched files whose current content is restored (embedded if small, otherwise referenced by path) into history after auto-compaction." (默认 `5`) / "compactionModel — Model used for chat compression (auto-compaction). Leave empty to fall back to the main model." / "`/compress-fast` — Fast compression without AI — strips old tool outputs and thinking parts" / "auto-compaction also fires once the number of tool-returned images accumulated in history reaches `screenshotTriggerThreshold`" (默认 `20`)
- url: https://qwenlm.github.io/qwen-code-docs/en/users/configuration/settings/
- source_type: primary
- published: 2026-10-03 (page "Last updated" date)
- confidence: high
