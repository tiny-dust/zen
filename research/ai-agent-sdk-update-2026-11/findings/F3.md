## 4. 不优先做与未决问题

| 项目 | 判断 |
| --- | --- |
| SDK 大版本迁移 | 暂缓。先由 F1 核实官方版本/迁移兼容；本地已经用 ToolLoopAgent、Output.object、toolApproval 等，不能以“还停在 generateText 老循环”为迁移理由 |
| 总预算/循环检测 | 有价值但非首批：当前明确无 run 总步数上限且有回归测试。若用户需要，应先设计可选 token/成本/时间预算，默认保留现状，并确认等待审批/问询不消耗墙钟预算、多 Agent 汇总口径和预算终态。单纯改 isStepCount 不会限制外层 run |
| 动态工具筛选 | 已有 enabled 工具汇总与 skill 按需加载（`agent-tools.ts:457`），不是完全静态工具表；逐步相关性过滤/工具搜索可以降低大量 MCP schema 成本，但需先量化工具 schema token，并保留用户点名工具、审批与稳定缓存前缀，不先加新框架 |
| Durable multi-agent | 消息恢复不是 durable 调度；目前子任务 controller、等待用户、重试状态在内存。跨进程恢复会涉及副作用去重/审批持久化/状态版本，不是小范围补丁，不列首批 |

| 评估 | 已有大量行为/协议测试；不能据此声称有任务成功率数据集、跨版本 benchmark 或端到端供应商质量门禁。应先将现有 mock/回放夹具作为升级门禁，是否建设评估数据集由后续确认 |
| 验证状态 | 静态取证完成；测试与类型检查均未运行，因此不提供通过率、运行耗时或覆盖率数字。没有读取任何 SQLite 实例、密钥文件或环境凭据 |
