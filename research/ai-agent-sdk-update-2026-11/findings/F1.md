# F1 — AI SDK 官方版本与 agent/tool 安全机制

## 结论

截至访问日 **2026-11-19**，npm 官方 `latest` 为 **ai 7.0.177**，发布日期为 **2026-11-18 19:03:24.841 UTC**（北京时间 2026-11-19 03:03:24.841），不是把访问日期当作发布日期。Zen 声明及安装的版本均为 **7.0.169**，只落后同主次版本的 8 个补丁编号，不能据此称为“落后一个大版本”。AI SDK 7.0.0 于 2026-06-25 发布，在本次约六个月窗口内。

官方当前正文已记录 ToolLoopAgent、集中式 `toolApproval`、输入 schema 校验、结构化 output、动态工具暴露、取消、分层超时和自定义预算停止条件。**可用机制不等于 Zen 缺失，也不等于必须迁移到 ToolLoopAgent**。本视角依授权仅读取两个本地 package.json，具体已有实现由源码视角核对。
