# 调研问题

截至 2026-11-19，核实最近约 6 个月及当前官方文档中 AI、AI Agent、Vercel AI SDK 的可用进展，对照本地 Zen，筛选收益明确、风险可控的更新。全球官方一手来源优先；检索时间不等于发布日期，不将未来日期或搜索摘要当作已发布事实。用户选择：先报告与方案，确认后才修改产品代码、安装依赖或迁移。

## 子问题清单

1. 当前 AI SDK 的稳定版本和 agent/tool/structured-output API 能由官方资料验证，与 Zen 已安装版本的差距可被确定。
2. 官方 SDK 对工具执行审批、工具输入校验、循环预算及取消提供明确机制，可与 Zen 实现对照。
3. 主流 AI Agent 官方实践对上下文管理、动态工具暴露和 prompt caching 提供可复用机制。
4. 主流 Agent SDK 对恢复、观测、评估及多 agent 编排提供可验证能力。
5. Zen 当前相关能力可通过源码、调用链与测试定位，不能把已有能力列作缺失。
6. 更新建议可以按收益、风险、改动范围及验证方式排序，而不盲目追版本或重写框架。

## 预算档位

默认档；总子 agent 不超过 5（含复核）；外部引用来源不超过 15；补查最多一轮。分配：F1 AI SDK，F2 官方 Agent 与模型实践，F3 Zen 源码，1 个独立复核。
